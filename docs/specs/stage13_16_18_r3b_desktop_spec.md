# 1. Summary

**This is the desktop full-settings variant of Run 3b (v2.0.2-desktop).** It keeps the v2.0.1-desktop settings and adds one runtime fix: cuDNN is disabled only around the expected-gradients backward pass, because the cuDNN GRU backward does not run when the frozen network is in eval mode. Stages 13, 16 and 18 run together as one run (no `--part` split, no 60-minute cap). D20 refit counts are restored: stage 13 gradient boosting B = 50, stage 18 GRU B = 20, at all seven core landmarks (24, 48, 72, 120, 168, 240 and 336 h). Every file the script writes goes under `data\\processed\\ladder\\DESKTOP_FULL_PLAN\\` only (published folder `stage13_16_18_r3b\\`, pending folders, cache, internal files, and `README_DESKTOP.txt`). Training and expected-gradients attribution use CUDA if available, otherwise CPU (logged). Frozen A+B+C reproduction forward passes run on CPU in float32, matching the laptop Run 2, even when CUDA is available.

* **Run 3b (this package):** stage 13, attribution stability (H7) on the 24 h rows; stage 18 sequence attribution of the D19 GRU A+B+C at all seven core landmarks; stage 16, the Layer C tensor SVD. Train and validation rows only; no test row is read, and Run 3a output is not required.
* Script: `scripts\\stage13_18_r3_desktop\\r3b_desktop_full.py` (`r3b_desktop_full v2.0.2-desktop`).
* Exit codes: 0 ok; 2 stopped on an input check (nothing written); 3 build or release-gate failure (nothing published).
* Runtime: box synthetic full-settings runs of this desktop script (CPU torch, default D20 counts). x3 fixture (LR winner, so no stage 13 GB jobs): 1242.6 s, exit 0, release gate ok (stage 13 117 s, stage 18 782 s at all seven core landmarks with B = 20, stage 16 342 s). GB-winner fixture (base size, GB B = 50): 2560.6 s, exit 0, release gate ok (stage 13 2261 s, of which the GB jobs were 2208 s: b1 602 s / 11.7 s per refit, b2d 706 s / 13.7 s per refit, winner a2+b2s 900 s / 17.6 s per refit; stage 18 180 s at all seven core landmarks with B = 20; stage 16 107 s). Real data is about 4× the x3 wall time; gradient-boosting refits scale with B and are CPU-bound; the GPU helps only the GRU attribution (stage 18). There is no 60-minute time cap. Desktop estimate: about 4–6 hours on the real data if the tabular winner is gradient boosting, as it is on the real Run 2 (stage 13 GB is CPU-bound and dominates; scale from the base-size GB jobs at ~4× the x3 size; the GPU helps only the GRU attribution, about 10–20 min).

# 3. Stage 13: attribution stability, H7

* Models: the ordinal LR (proportional odds, λ = 1) at every level a0–b2p and on the winner's matrix; the tabular winner (Frank–Hall gradient boosting, the frozen stage 12 hyperparameters: learning rate 0.1, 7 leaves, 200 iterations) on b1, b2d and the winner's matrix (a0+b0 at full width on the real data). Gradient boosting on b2s is read off the b2d refits when the b2d trees never split on a φ2-dup copy and the full-train b2s and b2d fits coincide (otherwise refitted). Outcome 2 (secondary): ordinal LR on b1, b2s and b2d.
* Refits: subject bootstraps of train; **B = 50 for the ordinal LR, B = 50 for gradient boosting** (D20 restored).
* Attribution target E[Y | x] = Σ_j P(Y > j | x) (plan §11) on a fixed seeded validation sample of 500 rows; ordinal LR: exact interventional linear SHAP; gradient boosting: exact path-dependent TreeSHAP of each threshold margin, carried to P(Y > j | x) by the rescale rule and summed. Home-made (no `shap` package on the laptop) and checked in the tests against brute-force Shapley values.
* Summaries: median Kendall τ of the mean-|SHAP| vectors between refit pairs (with IQR), split into grouped (summary statistics, z-flags, renal Cr/AKI, duplicated copies) and ungrouped columns; within-group credit split; the interventional vs conditional TreeSHAP gap on the full-train fit (200 validation rows, 50 train background rows).
* H7 (plan 12.2 bracketed values): the median τ falls from φ1 (b1) to φ2-dup (b2d) by at least 0.10, more in the grouped than the ungrouped columns, and φ2-single (b2s) stays within 0.05 of φ1.
* In-script synthetic gate: a planted redundant group must split its credit and lower τ.

# 4. Stages 18 and 16

**Stage 18, sequence attribution.** Expected-gradients SHAP (GradientSHAP, 16 baseline-and-α draws per row, 100 train baselines) of E[Y | x] for the D19 GRU A+B+C, Outcome 1, on 300 validation rows per landmark at all seven core landmarks 24, 48, 72, 120, 168, 240 and 336 h; **B = 20 subject-bootstrap refits of train** per landmark with the frozen Run 2 configuration (D20 restored). Kendall τ between refits at three granularities (bin × channel, channel, day block / organ block); permutation importance of the frozen Run 2 model as the cross-check; input-type shares (values, masks, carried-forward flags, bin index, static A+B context, Layer A offset); TreeSHAP of the frozen A+B landmark models for the A vs B share. Tables may still lead with the later core landmarks in Vinai's H9 framing.

**Stage 16, Layer C tensor SVD (full settings, unchanged from the laptop package).** Train tensors (patients × bins × channels) at the seven core landmarks (all 14 for the angle table), normalized, raw (masked EM fit) and engineered-lite levels: HOSVD mode spectra with 20 null draws; Tucker by HOOI on the r1 × r2 × r3 grid with validation projection error on fixed train factors; CP-ALS (10 random starts + the HOSVD start) with CORCONDIA (reported as a core-consistency fraction) and 50 subject bootstraps for congruence (D18 thresholds 0.85 and 80 %); principal angles between landmarks; organ-block alignment of the channel factors against a permutation null; the labeled flattened baseline. No patient-mode loadings are written. In-script synthetic gate: a planted rank-3 tensor must be recovered. HOOI and CP fits still use a seeded sub-sample of at most 2000 train patients; the H17 padding probe and the optional loading-based model remain omitted.

3. the preceding v2.0.0-desktop Run 3a attempt on this desktop failed during validation-only verification, before any test row was read; the desktop test-use log is unchanged. This Run 3b does not score test rows
