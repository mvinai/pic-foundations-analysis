# 1. Purpose, research question, objectives, and the transform $\phi$

**Question.** For a fixed set of PIC encounters, which clinically informed transform of the raw tables gives the best design matrix as a data representation, or does the raw data already have that structure? "Best" is a six-criterion profile (§12): conditioning, compactness, predictive signal at matched width, low redundancy, SHAP attribution stability, and physiologic plausibility of imputed values. The submitted project outline (November 4, 2026) named the first five; the sixth was added in v11. The primary prediction target is Outcome 1, remaining ICU time after a landmark (9 ordered levels with death as the top level; §2); the inherited eight-class outcome of the 3.0 contract (ordinal8, named in the outline) is kept as a secondary target at the 24, 48, and 72 h landmarks.

**Objectives.** The plan has three objectives. Objectives 1 and 2 are those of the submitted outline and keep its team split; Objective 3 is an extension beyond the outline (Vinai's decision for v13) and does not replace any outline analysis.

**Transform.** The raw tables are turned into a design matrix by a row-wise transform $\phi_k(\cdot\,;\theta)$ with fixed domain knowledge $\theta$ (both are defined in the notation block below; age-normative curves, clinical cutoffs, AKI baselines, code-to-group and drug-to-group maps). $\theta$ is never fit to outcomes or to the data. Everything learned from data is fit on train only and counts as preprocessing (§7).

**Notation and the transform.** 

- **Encounters and raw records.** The index $i = 1, \dots, n$ labels encounters, with $n = 13{,}708$ (§2). The *raw record* $r_i$ is everything the PIC tables hold for encounter $i$ (age, sex, admitting diagnosis code, charted vital signs, laboratory values, prescriptions, surgeries, cultures). $X_{\mathrm{raw}}$ stacks the raw records, one row per encounter.
- **The reference tables $\theta$: one nested dictionary.** A reference-table choice $\theta$ is one complete nested dictionary (a lookup structure). Its top-level keys are feature names (HR, Cr, ICD, and so on). Each key maps to a nested lookup whose keys are conditions (an age band, a diagnosis code) and whose values are the reference parameters. For example,
$$\theta[\mathrm{HR}][\text{1--2 yr}] = (\mu, \sigma), \qquad \theta[\mathrm{ICD}][\text{J18.9}] = \text{Chapter J},$$
which reads: for heart rate in the 1--2 year age band the entry is the pair (reference mean $\mu$, reference standard deviation $\sigma$), and the ICD code J18.9 belongs to ICD-10 chapter J [numeric table entries and the exact age bands, from the cited sources]. The dictionary also holds the other fixed domain knowledge: the age-indexed cutoffs (such as the heart-rate cutoff $c$), the baseline creatinine by age ($\theta[\mathrm{Cr}]$, used for AKI staging), and the code-to-group, drug-to-group, surgery-to-type, and measurement-to-organ-system maps. **Patient values are never keys.** A patient's heart rate or creatinine is not looked up in $\theta$. The row's own age only selects which band applies, and the measured value is an input that $\phi$ combines with the looked-up parameters. In later sections $\mu_{\mathrm{HR}}(a)$ and $\sigma_{\mathrm{HR}}(a)$ denote the two components of $\theta[\mathrm{HR}]$ at the band containing age $a$, and $\mathrm{Cr}_{\mathrm{base}}(a)$ and $c(a)$ the corresponding entries for baseline creatinine and the cutoff. ($\sigma_{\mathrm{HR}}(a)$ is a table entry, not a singular value; singular values carry a plain index, $\sigma_i$.) $\theta$ is domain knowledge read from published sources and the project reference tables [file names]; it is a lookup and is never fit to the data or to outcomes.
- **The set $\Theta$ (capital theta).** $\Theta$ is the family of admissible dictionaries that share the same top-level feature keys but may differ in values, age bands, or cutoffs (for example another published heart-rate reference curve, or shifted age bands). A dictionary with different feature keys (a feature added or dropped) is a change of representation, that is, a change of $k$ below, and not a change of $\theta$.
- **Representations and families.** The representations form a *representation hierarchy* of levels indexed by $k \in \{0, 1, 2\}$: Level 0 ($\phi_0$, raw native-unit summaries), Level 1 ($\phi_1$, normalized: age-normalized and grouped), and Level 2 ($\phi_2$, organ-system blocks). It is a hierarchy of increasing clinical abstraction: coarsening steps give nested column spaces, while threshold features can add directions outside them, so the hierarchy is not strictly nested. The *$k$-th representation* is the output of the level-$k$ transform. Let $p$ be the number of raw features (the dimension of the raw feature space) and $q_k$ the number of engineered columns of representation $k$. For a fixed dictionary $\theta$, the transform is a function
$$\phi_{k,\theta} : \mathbb{R}^{p} \to \mathbb{R}^{q_k}, \qquad r_i \mapsto x_i ,$$
where the first arrow gives the domain and codomain (raw feature space to engineered feature space), and the second arrow, $\mapsto$ (read "maps to"), says what happens to one element: the raw record $r_i$ is sent to its engineered vector $x_i = \phi_{k,\theta}(r_i)$. $\phi_{k,\theta}$ is a function (each $r_i$ gets exactly one $x_i$) but generally many-to-one: different raw records can give the same engineered vector, as in coarsening, where the codes J18.9 and J12.9 both become chapter J and cannot be told apart at the chapter granularity. The *family* of transforms for the $k$-th representation is
$$\Phi_k = \{\, \phi_{k,\theta} : \theta \in \Theta \,\}.$$
Given $k$ and $\theta$, the transform $\phi_{k,\theta}$ is completely determined by $\theta$: it has no other free parameters. The notation $\phi_k(r_i;\theta)$ means the same as $\phi_{k,\theta}(r_i)$.
- **The fixed choice $\theta^{\ast}$.** One element $\theta^{\ast} \in \Theta$ is chosen *a priori*, before any outcome is examined, and every primary result uses $\theta^{\ast}$ only.
- **Row-wise application.** For level $k$, encounter $i$ has the feature vector
$$x_i = \phi_k(r_i;\,\theta^{\ast}) \in \mathbb{R}^{q_k},$$
where $q_k$ is the width (number of columns) of level $k$. The design matrix $X^{(k)} \in \mathbb{R}^{n \times q_k}$ has rows $x_i^{\top}$, and $X^{(k)} = \phi_k(X_{\mathrm{raw}};\theta^{\ast})$ is shorthand for applying $\phi_k$ to each row separately. Row $i$ depends only on $r_i$ and $\theta^{\ast}$, never on other rows. The map $\phi_k$ reads each row's own fields (for example its age $a_i$) to pick the matching entry of each age-indexed table in $\theta^{\ast}$.
- **Worked example (heart-rate z-score, level $\phi_1$).** Let encounter $i$ have age $a_i$ at ICU admission and a heart-rate value $h_i$ in beats/min [which summary of the window, e.g. the median; to be fixed]. Then the HR feature in $x_i$ is
$$z_i^{\mathrm{HR}} \;=\; \frac{h_i - \mu_{\mathrm{HR}}(a_i)}{\sigma_{\mathrm{HR}}(a_i)},$$
with $\mu_{\mathrm{HR}}$ and $\sigma_{\mathrm{HR}}$ taken from $\theta^{\ast}[\mathrm{HR}]$ at the band containing the row's own age $a_i$. Two encounters with the same $h$ but different ages $a_1 \neq a_2$ receive different $z$ values whenever $\mu_{\mathrm{HR}}(a_1) \neq \mu_{\mathrm{HR}}(a_2)$ or $\sigma_{\mathrm{HR}}(a_1) \neq \sigma_{\mathrm{HR}}(a_2)$, while level $\phi_0$ keeps $h_i$ itself unchanged. The flag $z_i^{\mathrm{HR}} > 2$ is then a function of $r_i$ and $\theta^{\ast}$ alone. [Numeric version of this example: the values $\mu_{\mathrm{HR}}(a_i)$ and $\sigma_{\mathrm{HR}}(a_i)$ must come from the chosen reference table; none are supplied here.]
- **Sensitivity to $\theta$.** Replace $\theta^{\ast}$ by another $\theta' \in \Theta$ (for example an alternative published reference curve or shifted cutoffs [list of alternative $\theta'$, fixed before real data]). The same rows then give $x_i' = \phi_k(r_i;\theta')$ and a different matrix $X^{(k)}_{\theta'}$. The criteria of §12 are recomputed under each $\theta'$, and the report states how much the comparison between levels changes. The alternatives are chosen from the literature, not tuned to outcomes.
- **What is learned from data.** Vocabularies, rare-category pooling, imputation (including the v11 matrix-completion arm, §6), winsorizing, scaling, SVD and CPQR bases, hyperparameters, and calibration are fit on train only. They are preprocessing applied after $\phi_k$ (§7), and they are not part of $\theta$.
- **The letter $k$.** In this section and in the principal-angle subsection of §9, $k$ indexes levels. In §8 to §10 it also denotes a target rank or matched width, stated where it appears. Bins of Layer C are indexed by $k$ in §6 and §12.3 (bin $k$ covers $[t_0 + 6k, t_0 + 6k + 6)$), and $K$ is the number of ordinal classes in §10; the meaning is stated where it appears. Two further overloads are separated by context: in this section $p$ is the number of raw features, while from §7 on $p$ is the number of columns of the matrix under study (for level $k$ that is $q_k$); and $q_k$ here is the width of level $k$, while $q$ in §6 is the per-bin width.

*Reading the figure.* The top flow is: baseline features (time-invariant), then admission risk (the baseline risk, fed by illness severity), then time bin 1, $\dots$, time bin $i$, $\dots$, the final active time bin, and then the masked time bins. Admission risk leads to the baseline risk profile. Time bin 1 leads to landmark 1, time bin $i$ to landmark $i$, and the final active bin to the end-of-encounter outcome. The brace below the blocks shows that $\phi_\theta$ maps the raw features (the raw records $r_i$) to three blocks: *baseline features (time-invariant)*, namely demographics, anthropometrics, comorbidities (underlying medical conditions), and encounter-level characteristics; *illness severity*, an aggregate state representation of the initial 24 h, namely physiologic state, laboratory profile, and interventions; and the *time-sequence state*, the time-bin state representations, namely physiology, lab profile, and interventions. [The three blocks correspond to Layers A, B, and C of §4 to §6; to be confirmed.] The figure counts bins from 1, while §6 counts them from 0.

- *Illness severity and the time bins.* The illness-severity block uses only data from before the landmark. It summarizes the initial 24 h, which overlaps time bins 1 to 4 when bins are 6 h wide. For the 24 h landmark the two are the same window of data (the first 24 h), so that window is the only overlap and nothing beyond it is counted twice.
- *Masked time bins.* Masked bins are padding after the encounter ends. They carry no observations, but the number of masked bins reveals how long the encounter lasted, which is a source of sequence-length leakage. Landmark designs remove it: a prediction at landmark $t$ uses only the bins before $t$, for encounters still active at $t$ (§6).

**Representation hierarchy.** Within each layer, every level uses the same rows, the same split, and the same fixed fields. Only the granularity of the engineered fields changes, so differences between levels are associated with that step.

**Domain knowledge.** Domain knowledge enters in two places: the form of each transform $\phi_k$ (which clinical constructs are built, which defines the level) and its fixed parameters $\theta$ (the reference values those constructs use). Neither is fit to outcomes; both are specified a priori. The structure of $\phi_k$ (pooling codes into chapters, age z-scoring, organ-system grouping) is a clinical choice; for example, Level 2 mirrors how clinicians review patients by organ system. This a-priori specification is what lets differences between levels be associated with the clinical representation rather than with anything learned from data.

Two structural facts shape the design and are tested, not assumed:

- *Coarsening is linear.* *Coarsening* means merging fine categories of a categorical field into fewer, broader groups, for example ICD-10 diagnosis codes into ICD-10 chapters. Let $e_c \in \{0,1\}^n$ be the one-hot column of code $c$ (entry $i$ is 1 iff encounter $i$ carries code $c$). For a chapter $G$ (a set of codes), the chapter column is the sum of the one-hot columns of its codes,
$$e_G \;=\; \sum_{c \in G} e_c .$$
In matrix form, $X_{\mathrm{chapter}} = X_{\mathrm{code}}\, M$, where $M \in \{0,1\}^{d_{\mathrm{code}} \times d_{\mathrm{chapter}}}$ has $M_{cG} = 1$ iff code $c$ belongs to chapter $G$. Every column of $X_{\mathrm{chapter}}$ is therefore a linear combination of columns of $X_{\mathrm{code}}$. Writing $\operatorname{col}(X) = \{Xw : w\}\subseteq \mathbb{R}^n$ for the column space (the span of the columns of $X$), this gives $\operatorname{col}(X_{\mathrm{chapter}}) \subseteq \operatorname{col}(X_{\mathrm{code}})$. If $\phi_1$ and $\phi_2$ only pool $\phi_0$ categories in this way, the column spaces are nested,
$$\operatorname{col}\bigl(X^{(2)}\bigr) \;\subseteq\; \operatorname{col}\bigl(X^{(1)}\bigr) \;\subseteq\; \operatorname{col}\bigl(X^{(0)}\bigr)$$
(columns centered, full category sets). The principal angles between nested spaces are zero (§9), and the hierarchy then measures lost resolution, not new directions.
- *Thresholds and age bands are nonlinear.* Let $\mathrm{HR}_i$ be the heart rate and $\mathrm{age}_i$ the age of encounter $i$, and let $c(\cdot)$ be the age-indexed heart-rate cutoff in $\theta^{\ast}$. The threshold indicator
$$f_i \;=\; \mathbf{1}\{\mathrm{HR}_i > c(\mathrm{age}_i)\}\;=\;\begin{cases}1 & \mathrm{HR}_i > c(\mathrm{age}_i),\\ 0 & \text{otherwise}\end{cases}$$
is a step function of $(\mathrm{HR}_i, \mathrm{age}_i)$, so in general it is *not* a linear combination of the raw columns, even when those columns include $\mathrm{HR}_i$ and $\mathrm{age}_i$. It is the nonlinear contrast to coarsening. Flags, AKI stage, z-scores by age band, and the age band itself can therefore add directions outside $\operatorname{col}(X^{(0)})$. Linear versus nonlinear recovery (§9) measures how many and how large.

**Toy illustrations (not PIC estimates).** (i) Two standardized columns with correlation $\rho$ have Gram-matrix eigenvalues $1 \pm \rho$, so the Gram condition number is $(1+\rho)/(1-\rho)$ and the matrix condition number is $\kappa_2 = \sqrt{(1+\rho)/(1-\rho)}$, which grows without bound as $\rho \to 1$. (ii) Duplicate a column $x$ as $x_1 = x_2 = x$ and fit $f = \beta x$. A ridge fit splits the coefficient equally ($\beta/2$ each), and SHAP credit follows the split. For near-duplicates, the split moves from one bootstrap refit to the next while the group total stays put. These are the mechanisms behind H1 and H7. A prior pilot on simulated data computed $\kappa_2$, null directions, stable rank, $k_{95}$, CUR and angle comparisons and is the baseline. None of it is claimed as new, and none of its numbers are cited as PIC findings.

Layer A is what is known at ICU presentation (static context, including the approved 6 h pre-ICU lookback); Layer B summarizes the first 24 hours and is held fixed at every landmark; Layer C is the sequence of six-hour bins up to the landmark $L$, with $L$ every 24 h from 24 to 336 h. ## 2.3 Targets: two landmark-forward ordinal outcomes (amendment A1.2; decided November 10, 2026)

**Why the target changed.** At 24 to 72 h, Layers A and B carry most of the predictive signal, so the sequence layer has little room to contribute. Extending the landmarks to 336 h gives Layer C up to 56 bins of trajectory, but the inherited ordinal8 outcome is built largely from total ICU-stay bands and collapses at late landmarks (levels 0–2 fall under 72 h, 3–4 between 72 and 168 h, 5 between 168 and 336 h, and 6 at 336 h or more among survivors; only three levels remain at 168–240 h and the outcome is binary at 336 h). The primary outcome is therefore defined **from the landmark forward**. For an encounter eligible at $L$, two separate ordinal outcomes describe what happens after $t_0 + L$; they are modeled and reported separately, never combined.

**Outcome 1: remaining ICU time (primary; 9 levels).** For survivors, the time from $t_0 + L$ to ICU discharge (the encounter's last OUTTIME).

| Level | Definition (worst to best) |
|---|---|
| 8 | Died in hospital (any time after $L$) |
| 7 | Remaining ICU time over 336 h |
| 6 | Over 240 h, up to 336 h |
| 5 | Over 168 h, up to 240 h |
| 4 | Over 120 h, up to 168 h |
| 3 | Over 72 h, up to 120 h |
| 2 | Over 48 h, up to 72 h |
| 1 | Over 24 h, up to 48 h |
| 0 | 24 h or less |

**Outcome 2: post-ICU course (key secondary; 5 levels).** A surrogate for how tenuous or dependent the patient was at ICU discharge, since PIC records no organ function or support at ICU out-time.

| Level | Definition (worst to best) |
|---|---|
| 4 | Died in hospital (any time after $L$) |
| 3 | ICU readmission more than 24 h after ICU OUTTIME (any timing) |
| 2 | No readmission; post-ICU hospital stay over 14 days |
| 1 | Post-ICU stay 7–14 days |
| 0 | Post-ICU stay under 7 days |

**Rules.** Death takes precedence in both outcomes; for readmitted patients, Outcome 1 is measured to the index encounter's last OUTTIME. A readmission is a return to the ICU during the same hospitalization more than 24 h after OUTTIME (returns within 24 h are already merged by harmonization); the earliest readmission sets the level, and readmission levels take precedence over post-ICU stay levels. Readmission timing (24–48 h, 48–72 h, over 72 h) is descriptive only. Post-ICU stay is hospital discharge minus ICU OUTTIME, not total hospital LOS, with band edges under 7 d, 7 to under 14 d, and 14 d or more. Remaining ICU time includes within-encounter gaps (continuous clock). PIC stays are complete, so there is no censoring. **Index HADM tie-break:** encounter in-time is the earliest stay INTIME and out-time the last OUTTIME; when the last stays tie on OUTTIME with different HADMs, the HADM with the latest DISCHTIME supplies Outcome 2's DISCHTIME and the hospitalization searched for readmissions (encounter times unchanged). **Unassignables** (no readmission and no usable discharge time) are reported on their own line, assignable + unassignable = eligible is an acceptance check, and the audit found zero. **Double counting:** every readmission stay more than 24 h after OUTTIME is itself a cohort index encounter (`readmit_index_overlap` equals the same-HADM readmission count, for example 160 / 160 in train at 24 h); the policy is `keep_both`, which is safe because the split is by patient, the bootstrap resamples patients, and Layer A recency features use only information before each encounter's own INTIME.

**Level support (band-support audit, November 10, 2026; 14 landmarks $\times$ splits; release gate ok, 766 primary and 25 complementary suppressed cells, none recoverable).** Outcome 1: all 9 levels have at least 12 encounters in every split and landmark (minimum 12: test, level 2, 336 h), so **no merges**; level 7 (over 336 h) is the largest level, 22% of eligible at 24 h and 48% at 336 h (a 504 h cut is a future option, not adopted). Outcome 2 was first drafted with 8 levels (readmission split into 24–48, 48–72, over 72 h; post-ICU stay split at 30 d); the readmission sub-levels were below 10 in validation and test at every landmark and the over-30 d level below 10 in validation from 24 h and in test from 72 h, so Vinai **merged them to the 5 levels above**. Train supports all 5 levels to 336 h (readmission at least 42 in the final run); validation and test readmission counts fall below 10 at 336 h, so late-landmark Outcome 2 evaluation is interpreted cautiously. The under-7-day level holds 77–87% of survivors (a split into under 3 d and 3–7 d was considered and not adopted).

**Secondary targets.** (i) Outcome 2 as above. (ii) The inherited **ordinal8** (3.0 contract §5.5, death as class 7) at the 24, 48, and 72 h landmarks only, for continuity with the 3.0 paper and the submitted outline; its classes are: 0 alive, ICU $<$3 d, hospital $<$7 d; 1 alive, ICU $<$3 d, hospital 7 to $<$14 d; 2 alive, ICU $<$3 d, hospital $\ge$ 14 d; 3 alive, ICU 3 to $<$7 d, hospital $<$14 d; 4 alive, ICU 3 to $<$7 d, hospital $\ge$ 14 d; 5 alive, ICU 7–14 d; 6 alive, ICU $>$14 d; 7 died (prolonged ICU stay is `icu_los_hours` $>$ 336; alive with ICU LOS exactly 14.0 d is class 5). Classes 4 and 5 are expected to be sparse; the v12 handling of sparse classes (per-class counts before modeling, class weighting as a grid option, pooled-threshold metrics, cumulative-link models that need no per-class parameters, pooling only as a sensitivity analysis) applies to ordinal8 unchanged. (iii) **In-hospital mortality** (binary) at every landmark, as a sanity check; its threshold matches the death level of each ordinal outcome. v12's ordinal4 sensitivity scale and the binary composite (death, ICU $>$ 14 d, or hospital $>$ 30 d) are **dropped** (V7, November 16, 2026).

**Landmark analysis design (V5, November 16, 2026; replaces the stacked primary of A1.5).** *Objective 2 primary:* the levels of Layers A, B, and AB are compared on the **24 h landmark rows**, one row per encounter alive and still in the ICU at $t_0 + 24$ h ([N_eligible omitted] encounters; train 6,556, validation 1,399, test 1,406), with Outcome 1 measured from 24 h; the Layer C levels on the 24 h prefix join that comparison (§10). *Co-primary:* the **Layer C landmark-forward analysis**: the Layer C prefix up to $L$ (bins $0, \dots, L/6 - 1$, all with `mask_valid` = 1 by eligibility) is added to A+B and scored on Outcome 1 measured from $L$, fitted **separately at each core landmark** (24, 48, 72, 120, 168, 240, 336 h) on the encounters eligible at $L$, one row per encounter. The other seven landmarks are fitted and reported the same way as secondary results, so all 14 landmarks are reported. Every row of a patient stays in the inherited split, and inference uses the patient-level cluster bootstrap.

**Stacked landmark model (sensitivity, Layer C only).** One row per encounter per landmark at which it is eligible, with landmark time (hours or a spline) as a covariate, fitted for A+B and A+B+C. Layers A and B are fixed at $t_0$ and the first 24 h, so an encounter's A and B features are identical in all of its stacked rows; only the Layer C prefix, the landmark time, and the outcome change with $L$. Stacking therefore adds nothing to an A/B-only comparison (it would only reweight the 24 h question toward long stays) and is not used for one; for Layer C it pools the landmarks and borrows strength across them, which is why it is kept as a sensitivity analysis of the co-primary contrast. Within it, per-row weighting is used (each landmark is its own prediction question), with per-patient weighting (each patient's rows sum to 1) as a further sensitivity so long-stay patients do not dominate.

**Which rows each objective uses.** Objective 1 (unsupervised diagnostics) uses all train encounters of a layer ([N_train omitted] rows for A, B, AB) and, for C, the landmark-eligible train encounters. Objective 2 uses the 24 h landmark rows with Outcome 1 for the matched-width level comparison of A, B, AB, and the Layer C levels at 24 h (primary), and the encounters eligible at each landmark for A+B versus A+B+C (co-primary at the core landmarks), as above. The v12 whole-cohort tabular comparison (all [N_encounters omitted] rows, ordinal8, Layer B window truncated at OUTTIME) is **dropped** (V16, November 16, 2026): ordinal8 on the 24 h landmark rows (and at 48 and 72 h) keeps continuity with the outline, and the whole-cohort version would need a truncated Layer B window that the landmark design avoids. Objective 3 uses the landmark-eligible train encounters of Layer C (§12.3).

**Long-term goal and a limitation (kept from v12).** Vinai's longer-term plan is an ordinal target built from organ-system, utilization, and mortality or condition-at-discharge components on future data. In PIC only ICU time, hospital time, readmission, and mortality are available. LOS-based targets interact with windowing and masking: a shorter stay yields fewer open bins and more missing channels. The landmark-forward design removes the main shortcut (every eligible encounter at $L$ has the same observed sequence length, so open-bin count cannot act as a duration proxy), and the safeguards below handle the rest.

## 2.4 Leakage safeguards

| Safeguard | Rule |
|--------|-------------------------------------------------------------------------------|
| S1 | Layer B uses a hard cutoff at $\min(\mathrm{OUTTIME},\ t_0+24\,\mathrm{h})$; nothing at or after either enters a Layer B feature. Layer B is computed once and held fixed at every landmark; pre-landmark information after 24 h enters only through Layer C. |
| S2 | No LOS-derived feature: `icu_los_hours`, `span_icu_hours`, `icu_time_hours`, hospital LOS, window length, and rates normalized by window length are banned. Counts and exposure hours are capped at the window, not rescaled by it. Measurement counts per channel are audit descriptors and S4 probe inputs only, never features. Urine output in mL/kg/h is computed from charted intervals (§5.2, D30), never from total output divided by window length. |
| S3 | **Medication state machine (strict look-back, primary for all layers).** At each time step $t$, a course is a state computed only from documentation at or before $t$: active if the last documentation at or before $t$ is within the group cutoff (12 h vasoactive; 24 h for every other group; §5.3). Nothing documented after $t$ changes any feature at $t$, so a rebuild as of any landmark is identical by construction. The frozen 3.0 whole-stay rule is a comparison build only. ENDDATE presence is never a feature. |
| S4 | Leakage probe: a model using only window-shape proxies (per-channel observation counts and missing fractions) is trained and scored on validation; its validation QWK and EMD on Outcome 1 are reported next to the full models as a floor for "length information". |
| S5 | Sensitivity analysis on encounters still in ICU at $t_0 + 24$ h (the 24 h landmark cohort), where the Layer B window is always full. Under the landmark design this is the primary row set at $L = 24$ h; no whole-cohort comparison is kept (V16), so S5 needs no separate sensitivity run. |
| S6 | **Layer C landmark rule.** At landmark $L$, only bins whose end is $\le L$ (bins $0, \dots, L/6 - 1$) and only data available strictly before $t_0 + L$ enter; eligible encounters have no padded bin in that prefix. `mask_valid` (bin starts before OUTTIME) selects bins and is never a feature; the count of open or padded bins, time to OUTTIME, and any LOS-derived quantity are banned. |
| S7 | Targets, split labels, and IDs are keys only, never in `feature_columns`. |
| S8 | **Microbiology timing.** MICROBIOLOGYEVENTS has only CHARTTIME (specimen collection). M1 uses collection facts only (primary); M3 makes a result available at CHARTTIME + an assumed turnaround; M2 places results at collection (look-ahead, labeled, never used for primary results or the winner choice). Specimen susceptibility add-ons never reach M1 (base test code only, D12). |
| S9 | **Laboratory release timing (decided; replaces v12 S9).** PIC LABEVENTS has only CHARTTIME (about the collection time). Every lab result is available at **CHARTTIME + 1 h** (primary; +0 h and +2 h sensitivities) everywhere: the Layer B window, Layer C bins, the "available before $t_0 + L$" rule, and the pre-ICU lookback. A lab collected shortly before $t_0$ but released after $t_0$ enters Layer B. A result is never backfilled to its order time; triggered tests keep the ordered flag from the order time. Labs during surgery are not excluded from Layer C. |
| S10 | **Surgery timing (A2.1).** A surgery whose anesthesia end $T$ falls in $[t_0 - 24\,\mathrm{h},\ t_0 + 6\,\mathrm{h}]$ is a Layer A recent surgery and must never also appear as a Layer C event; Layer C surgeries have $t_0 + 6\,\mathrm{h} < T \le \mathrm{OUTTIME}$. Actual surgery duration is not used at the surgery's start (§6.4). |
| S11 | **Informative-missingness descriptors** (measurement metrics by Outcome 1 group and by mortality) are computed on train only, are descriptive, and are never used to choose, drop, or encode a feature. |
| S12 | **Readmission overlap.** Under `keep_both`, Layer A prior-admission and recency features use only information before each encounter's own INTIME (acceptance and leakage check). |

## 4.1 Surgery handling (decisions 12–18; A2.1, A2.2, A2.7, A2.10)

**Timing time $T$.** $T$ = ANES_END_TIME; if missing, SURGERY_END_TIME (fallback counted); if both are missing the surgery has no timing (counted as `invalid_time`). All times are relative to the harmonized $t_0$ and OUTTIME. **Classes:** *Layer A recent* if $T \in [t_0 - 24\,\mathrm{h},\ t_0 + 6\,\mathrm{h}]$ (Layer A only; **never also a Layer C event**, S10); *Layer C event* if $t_0 + 6\,\mathrm{h} < T \le \mathrm{OUTTIME}$, including surgeries in merge gaps (one ICU course; an `in_gap` descriptor may be kept); *remote* if in the same HADM and $T < t_0 - 24$ h (Layer A comorbidity-type feature; surgeries before ADMITTIME are kept and flagged); surgery in other hospitalizations is not used (prior-admission features cover it); *post-ICU* surgeries ($T >$ OUTTIME) are not features. **Counts (harmonization check, November 11, 2026):** recent 6,008, remote 850, Layer C 486, post-ICU 144 (total 7,488); 3,099 of the recent surgeries end in $(t_0,\ t_0 + 6\,\mathrm{h}]$. A surgery between two encounters of the same admission is assigned to the **later** encounter and classed relative to its $t_0$; one surgery may be a Layer C event for one encounter and remote Layer A history for a later encounter of the same admission (not leakage, because each encounter uses only information before its own $t_0$); audits that count surgeries assign each to one encounter and report the reuse separately. The earlier begin-time rule and its "surgery exactly at INTIME" edge question (v12 §4) are superseded and moot.

**Key and intraoperative vitals (decision 14).** The surgery key is `SURGERY_INFO.ROW_ID`, asserted unique and nonblank on all 7,488 rows; all rows are kept (`OPER_ID` is not unique: 389 (SUBJECT_ID, HADM_ID, OPER_ID) groups cover 889 rows of distinct surgeries). Each SURGERY_VITAL_SIGNS row is assigned to the ROW_ID in its key group whose anesthesia window [ANES_START_TIME, ANES_END_TIME] contains MONITOR_TIME (**strict window, primary**; $\pm$30 min sensitivity). Real-data check: of 1,944,187 rows, 17,640 have no SURGERY_INFO key; of the keyed rows the strict window assigns 97.8% and leaves the rest unassigned (about a quarter of those remain unassigned at $\pm$30 min); ambiguous rows are a count under 10. Unassigned and ambiguous rows are excluded from per-surgery summaries. Intraoperative summaries describe the surgery episode only and never overlap with Layer C channels; operating-room time is ordinary (empty) time in Layer C, which uses ICU-documented measurements only.

**Type, system, and complexity (MAP_v1).** The reviewed `surgery_complexity_map_v1.csv` (1,495 names, name-level only) gives each `standardized_name` a body system, a surgery type, a cardiac STAT category (G1, G2, G3, or NC) for cardiac operations, and a non-cardiac complexity group (I1 = minor/diagnostic plus catheter/interventional; I2 = minimally invasive; I3 = major open; the four-level intensity scale is a sensitivity analysis). **STAT and intensity are separate descriptors**: STAT is the cardiac risk marker; neither is ever used as a duration proxy.

**Why $\phi_1$ uses a type-specific duration band (decision 16).** The complexity–duration audit v1.7 (MAP_v1, release gate ok, November 11, 2026) found that complexity groups do not track duration: `big_discrepancy` = Y in every assessable system and pooled. Cardiac STAT medians were G1 1.9 h, G2 3.9 h, G3 3.1 h (Kendall $\tau$-b 0.177); GI 0.025; Hepatobiliary $-0.262$ (reversed); Thoracic $-0.066$; Urologic 0.173; pooled stratified $\tau$-b 0.076; the other six systems were not assessable. The pre-registered duration-versus-complexity criteria of the duration-audit spec (called D1–D5 there; written DA1–DA5 here to avoid a clash with the map decisions D1–D37) were applied, with DA2 on the signed reading decided November 10, 2026 (a discrepancy if $\tau_b < 0.2$, signed, so a weak *or* inverse association counts); the result was robust across sensitivities a, b, c, and e (d, during-ICU surgeries, not assessable); 2,000 bootstrap replicates; 1,137 primary and 880 complementary suppressed cells, none recoverable. **Decision:** $\phi_1$ = surgery type $\times$ type-specific duration band, replacing $\phi_1$ = type $\times$ universal band ($<$2 h / 2–4 h / $>$4 h), which remains a descriptive and sensitivity level; type alone is a further sensitivity level.

**Band rules (decided November 11–12, 2026).** Duration $D$ = SURGERY_END_TIME $-$ SURGERY_BEGIN_TIME, falling back to the anesthesia window (the same window as the duration audit). Ratio $r = D / $ train median of the surgery's own type: **short** $r < 0.75$; **expected** $0.75 \le r \le 1.33$; **long** $r > 1.33$ (sensitivity: within-type train tertiles). The own-type median is used only if the type has $\ge 10$ train surgeries (sensitivity $\ge 20$); fallback order own type $\rightarrow$ system $\times$ complexity group $\rightarrow$ system $\rightarrow$ all surgeries; types unseen in train go straight to the fallback. The type median uses `standardized_name` (collapsing combination names to the primary component is a sensitivity analysis). The band enters as a **3-level ordinal** alongside the type and system descriptors, **not** as a type $\times$ band cross-product. **Band-support audit (November 12, 2026):** 5,141 train surgeries, short / expected / long 22.3 / 50.1 / 27.5% (validation 21.8 / 49.5 / 28.7%, test 23.8 / 49.7 / 26.6%); 73 of 1,083 train types have their own median, covering 63% of train surgeries; 12.9% of validation and 12.5% of test surgeries have a type unseen in train; within-type band cells are sparse. The medians are frozen in `phi1_band_support_frozen_medians_MAP_v1.csv` (`e73c8b5a…`). **Still open (minor):** handling of durations over 24 h and ordering violations (each under 10 in every split).

**$\phi_2$ clusters.** Fit on train only, from type plus pre-incision and intraoperative vital-sign summaries; frozen before any modeling; they describe the surgery episode, not the ICU trajectory [cluster inputs and algorithm: open].

**Layer C surgery events** are described in §6.4 (placed in the bin of $T$, decision 18).

**Acceptance checks (A).** (1) [N_encounters omitted] rows per level, canonical order. (2) split equals `subject_splits.csv` for every row. (3) No banned column; no ED-derived column and no `sex_missing` column in any level. (4) Fixed fields (sex, first_careunit) byte-identical across levels. - **Fluids and urine output (D10, D17, D30; decision 20).** Fluid intake 1009 and urine output 1008 come from CHARTEVENTS. Charted total fluid output is dropped; **fluid balance and percent fluid overload are dropped** (not enough information in PIC); fluid intake in **mL/kg/day** (daily total of charted intake $\div$ weight) is the fluid-status surrogate, an acknowledged limitation. **Urine output** in mL/kg/h = volume $\div$ weight $\div$ hours since the previous entry, capped at 24 h (first entry: hours since $t_0$); the value goes in the bin containing its charting time, is never back-filled, is carried forward at most 24 h, and days without an entry stay missing (an empty bin is never read as zero). Weight-dependent columns use the weight rule of §4 and report the share with charted weight.
- **Panel masks (D33).** One shared mask per panel measured together: cytokines, TEG, urine dipstick, blood gas (column `mask_group`).
- **ALT, TSH (D26).** Merged for the measured indicator only; values are not features.
- **Serology (D11)** is dropped from the time-varying channels.

Every cutoff has a 0.5$\times$ / 2$\times$ sensitivity analysis. The **neuro set v1** (`3cc8f4ac…`, confirmed November 14, 2026) counts CNS infection (A17, A80, A81, A83–A89, G00–G09), head injury (S06, S07, T90), stroke and bleed (I60–I64, I67, I69, G45, G46, P52), and encephalopathy (G92, G93, P91, G36, G37) as neuro, plus the partial categories A39, S02, S09, R40 and Q28 (Q28.2 / Q28.3 only); seizures, CNS tumours, and hydrocephalus / malformations are not neuro (they "don't typically require osmotherapy"); G61, G70, G12, G71, G80 stay excluded. Groups with train prevalence below **1%** of encounters are dropped above $\phi_1$ (the v12 "[sparsity cutoff]", set as an approved starting default) and the drop is logged. The posterior pituitary injection is left out of the vasoactive group (a low-confidence map row, §18).

**Medication state machine (primary rule, Layers A, B, and C).** Per encounter and per course key (DRUG_NAME / DRUG_NAME_EN, summarized to the thirteen groups of the table above), documentation events are rows with a documented dose or documentation time. At each time step $t$ the machine uses only events with time $\le t$. (a) *Last documentation* $\ell(t)$ is the latest documentation time $\le t$. (b) *Active:* $\mathrm{active}(t) = 1$ if $t - \ell(t) \le \text{cutoff}$, with cutoff 12 h for the vasoactive group and 24 h for every other group (decided November 14, 2026; 0.5$\times$ / 2$\times$ sensitivity). (c) *Stop time:* the course stops at $\ell + \text{cutoff}$, taken at the first $t$ at which $\mathrm{active}(t)$ becomes 0. A later documentation after a stop starts a new course (reorders inside the cutoff merge into the same course). (d) *ENDDATE:* a documented ENDDATE at or before $t$ (and after the start) ends the course at that ENDDATE, even if the cutoff has not elapsed. An ENDDATE after $t$ is a future value and is ignored at $t$. (Assumption confirmed by Vinai on October 29, 2026: an ENDDATE at or before $t$ was known at $t$. The entry time of an ENDDATE is not in the data, so this is stated as a modeling assumption in the methods text.) (e) *Start:* the start is the first documentation time. For a date-only STARTDATE, the assigned start is used (the start of the first in-window bin on that date, as the contract assigns), clipped so that it is never placed after $t$; a date-only start on a later date than $t$ is future and ignored. (f) *Features at $t$:* `started` (course start in the window and at or before $t$, with active = 1 at some time up to $t$), `active` ($\mathrm{active}(t)$), `hours_on_course` ($t -$ start of the current course, 0 if inactive), `hours_since_stopped` ($t -$ stop time of the latest stopped course, empty if no course has stopped or one is active), and `ever_received` (any documentation at or before $t$, with pre-$t_0$ documentation limited to the approved 6 h lookback within the admissions of `hadm_id_list`, the same lookback as Layer A; V20, November 16, 2026). Layer B evaluates the machine at every time step in W and at the window end; `hrs_active` is the measure (total length) of the set $\{t \in W : \mathrm{active}(t) = 1\}$. Layer C evaluates it at the end of each bin (active in a bin = active at some $t$ in the bin's effective overlap [confirm against the contract's overlap rule]). ENDDATE is missing on 78.07% of prescription rows (after start on 21.92%), so most active flags are cutoff-implied, and the methods text must say so. **ENDDATE flags (audit spec §9.4).** A group is flagged if, among its courses with a valid ENDDATE, the cutoff-implied stop and ENDDATE differ by more than 24 h in more than 25% of courses, or if ENDDATE presence differs by more than 10 percentage points between splits; for flagged groups `hours_on_course` and `hrs_active` are low-reliability (kept as $\phi_0$/$\phi_1$ columns; interpretation rests on `active`, `started`, and `ever_received`). ENDDATE presence is never a feature.

**Comparison with the frozen 3.0 contract rule.** The frozen contract implementation sets the end of a course from the latest same-name documentation over the whole stay and merges reorders over the whole stay (end = ENDDATE if after start, otherwise latest documentation + 12 h or + 24 h; date-only end to next midnight). A later documentation can therefore extend an active flag at an earlier time. It is not used for primary results. It is built as a comparison and sensitivity variant (column prefix `frozen3_`): the differences from the state machine are counted (encounters and groups for B, encounter-bins for C), and the winning model is rescored once on the frozen-rule features as a pre-declared sensitivity analysis. Vinai's note: the frozen whole-stay computation should be corrected in the future deep-modeling iterations of the contract.

## 5.4 Microbiology

**Microbiology timing hierarchy (Layers B and C).** The 3.0 contract treats MICROBIOLOGYEVENTS.CHARTTIME as specimen collection, and the table has no result or report time. The columns are SPEC_ITEMID, SPEC_TYPE_DESC, ORG_ITEMID, ORG_NAME, AB_ITEMID, AB_NAME, `DILUTION_*` and INTERPRETATION. A result that is read at collection time would use information the care team did not have yet, so three timing levels are defined:

| Timing level | Role | Rule |
|------|------------------------|-------------------------------------------------|
| M1 | **Primary.** Collection-only, leak-free. | Features use only the fact and time of collection: culture sent, culture_count, specimen type (blood / urine / respiratory / CSF / other from SPEC_TYPE_DESC), hours_to_first_culture. No `ORG_*`, `AB_*`, `DILUTION_*`, or INTERPRETATION field is read. |
| M2 | **Sensitivity, "oracle timing".** Look-ahead, labeled as such. | Results (organism, positivity, resistance) are placed at the collection time. Rationale (Vinai): a result describes the state of the patient at the time of testing. The performance gain over M1 is reported as an upper bound of the leak contribution, never as a usable signal. |
| M3 | **Realistic delay.** The version to present in the paper. | A result is available only at CHARTTIME + an assumed turnaround: gram class [24 h]; organism identification and positivity [48 h]; susceptibility and resistance [72 h]; negative final (no growth) [120 h]. The turnarounds remain bracketed pending Vinai's confirmation; the sensitivity grid $0.5\times$, $1\times$, $1.5\times$ is the one Audit Stage 2 used. |

PIC has no separate gram-stain row, so the gram class at [24 h] is derived from the standardized organism name and is an approximation of a stain read [caveat to be stated in the methods text]. The three timing levels are compared on the same rows and splits (H11): M1 versus M3 asks whether microbiology adds real-time-usable signal, and M2 versus M3 measures how much of an apparent gain is hindsight. M1 is the primary timing level for the hierarchy results; M3 is the microbiology result shown in the paper. **In Layer B, most results fall outside the 24 h window**: a result enters the window only if CHARTTIME + turnaround is at or before the window end (INTIME + 24 h), so with the base turnarounds a gram class needs a collection at or before INTIME, identification needs one 24 h or more before INTIME, susceptibility 48 h or more before, and a negative final 96 h or more before; only pre-ICU collections qualify [share of collections before INTIME, and per result type, from data]. M3 in Layer B therefore equals M1 for most encounters, and the share of encounters where M3 differs is reported. In Layer C the results enter the later bins in which their availability time falls. Because availability is computed from CHARTTIME alone, the landmark rebuild identity (§6, check 13) holds for M1 and M3 by construction, and M2 is the only timing level for which it fails, by design.

**Organism categorization (M2 and M3 only).** ORG_NAME is first standardized (Chinese and English variants, case, spelling, punctuation) to a canonical name, then mapped to categories by the pinned **organism map v1** (`21f28448…`, 101 keys, keyed by name) [contaminant and resistance clinical rules: still bracketed for Vinai]:

## 5.6 Organ scores

*Modified pSOFA* (Matics and Sanchez-Pinto 2017) from the worst values in the window, with age-specific cutoffs from the publication [table into $\theta^{\ast}$]. **Five components** (D29): cardiovascular, coagulation, hepatic, renal, neurological; **the respiratory component is dropped** because P/F and S/F cannot be built reliably in PIC. Components that cannot be scored as published (for example the neurological component without GCS, and the cardiovascular component without vasoactive doses, since PRESCRIPTIONS has no infusion rates) are scored from the available pieces or omitted [rule per component], which is why the score is *modified*. **Neonatal note (D24):** the neonatal median total bilirubin is about 90–100 µmol/L (about 5–6 mg/dL, roughly 2 hepatic points) and largely reflects physiological jaundice; a neonatal sensitivity analysis (neonates excluded from, or scored separately in, the hepatic component) is reported. *Modified PRISM III* (Pollack et al. 1996): the published point scores from the worst first-24 h values, without the components PIC lacks (mental status, pupils; respiratory components that need FiO2) [component list; point scores only, not a licensed mortality equation]. *Phoenix* (Schlapbach et al. 2024) is not used because it is sepsis-specific. Scorers are deterministic functions of $\phi_1$ inputs and $\theta^{\ast}$, so they are part of $\phi_2$, not fit to data. Score inputs are kept as value plus mask even if §5.7 would place them in the indicator class, and are flagged.

# 6. Layer C: the sequence layer (56 bins, 24–336 h)

## 6.1 Geometry, validity mask, and landmark prefixes (A1.6, A2.4)

**Grid.** Bin $k = [t_0 + 6k,\ t_0 + 6k + 6)$ h for $k = 0, \dots, 55$ (0 to 336 h), truncated at OUTTIME (the last stay OUTTIME). An observation at exactly $t_0 + 24$ h belongs to bin 4; labs enter at their release time. The real layer is stored on the full grid $\mathcal{X} \in \mathbb{R}^{13{,}708 \times 56 \times q}$ in canonical order with a validity mask

$$\texttt{mask\_valid}[e, k] = 1 \iff t_0 + 6k < \mathrm{OUTTIME}_e,$$

that is, the bin starts before the end of the stay. Bins with `mask_valid` = 0 are **padding**: all values empty, every `*_missing` = 1, every `*_carried_forward` = 0, every event = 0; they never enter a mean, SD, imputation, winsorizing, scaling, or decomposition statistic, and nothing is carried into them. `mask_valid` selects cells; it is **never a feature**, and neither is any count of open or padded bins (S6, I7).

**Landmark prefixes.** At landmark $L \in \{24, 48, \dots, 336\}$ h, the input is the prefix of bins $0, \dots, L/6 - 1$ (4 to 56 bins) for encounters eligible at $L$ ($\mathrm{OUTTIME} > t_0 + L$), using only data available strictly before $t_0 + L$. Because every bin of an eligible encounter's prefix starts before $t_0 + L <$ OUTTIME, **every prefix bin is valid**: the landmark tensors contain no padding, and every eligible encounter at $L$ has the same observed sequence length, so the number of open bins cannot act as a duration shortcut (A1.7). The bin index is allowed as a position input (it is known at $L$). Layer A and Layer B are attached unchanged to every landmark row.

**Fixed 72 h window sensitivity (A1.6).** Layer C limited to the 12 bins immediately before $L$ (bins $L/6 - 12, \dots, L/6 - 1$ for $L \ge 72$ h), so short- and long-stay patients supply equal history.

**The frozen 3.0 Layer C file is retired (V8, November 16, 2026).** The 3.0 `layer_c_features.csv` (28 bins, 168 h, the 16 original contract channels) is not an input, is not pinned, and is not a reconciliation control: no check compares bins 0–27 with it. The **Stage 3 real-layer builder** (§13) is the one common builder of the real Layers A, B, and C; it builds the 56-bin Layer C from the raw tables on the pinned channel map (§5.1) with its own binning code (bin edges, effective intervals, padding rule, masks before LOCF, carry caps), and it absorbs the v12 stage 08x (the Layer C lab extension).

## 6.6 Missingness and imputation comparison arms (Layer C)

**Missingness and imputation comparison arm (v11 extension; proposed, no results).** A missing value in the ICU is often a clinical decision (a test not ordered, a drug not given), so the pattern of missingness carries information, and the way gaps are filled is part of the representation, not a neutral cleaning step. Ali, Jiang, et al. (§19) compared clinician-derived imputation rules with low-rank matrix completion in an adult surgical ICU. Matrix completion was more accurate on masked known values (mean RMSE 0.80 vs 1.37 over 100 bootstrap samples), but it produced impossible values (negative ventilator times, negative laboratory values), and both imputations led to similar downstream clusters. v11 tests the same trade-off in this pediatric cohort, inside the Layer C representation hierarchy; v13 keeps the arms and assigns them by the sparsity classes of §5.7.

- *Masks in every arm and every layer.* The observation masks (`*_missing`, created before LOCF) and the `*_carried_forward` flags are kept as columns in all layers and in every imputation arm, so a filled-in value never hides the fact that it was not measured. The contract LOCF caps are not changed; the arms only fill valid cells (`mask_valid` = 1) that are still empty after the LOCF rules. Padded bins are never imputed. Event channels are not imputed (absent = 0 is already their definition).
- *Arm (r), reference.* The v10 rule (§7): train median per column plus the mask.
- *Arm (a), age-specific pediatric clinician rules plus masks.* The adult rules in §19 ("assume normal", "carry forward, else a default", "assume no treatment") are adapted for children. *Normal-value fill:* an empty physiologic or laboratory cell receives the age-appropriate normal value for the encounter's age band, read from the fixed tables in $\theta^{\ast}$ (for example $\mu_{\mathrm{HR}}(a_i)$), never fit to outcomes. *Carry forward with defaults:* the contract LOCF (§6 table and caps) first; a cell still empty receives the age-band default [whether arm (a) may carry beyond the contract caps: decision open]. *Assume no treatment:* absent treatment and event indicators stay 0. [Exact age-specific norm tables per channel, their sources, and the default for each channel: to be specified; open.]
- *Arm (b), low-rank matrix completion plus masks.* The continuous value columns of the training landmark prefix (the flattened $n \times (bq)$ landmark-prefix matrix, value columns only, Dense and eligible Moderate channels only) are completed by a low-rank model, for example nuclear-norm-regularized soft-impute or a rank-$r$ alternating least squares fit on the observed entries. The completion is fit on train rows only. A validation or test encounter is filled by *folding in*: its row coefficients are solved from its own observed entries against the train-fitted column factors, with no refit. [Algorithm, rank-selection rule (for example the observed-entry hold-out within train, or the §8 permutation-null count), regularization, convergence tolerance: open.]
- *Arm (c), optional: bounded (constrained) low-rank completion plus masks.* The same completion with constraints: non-negativity for quantities that cannot be negative (counts, concentrations, durations) and the physiologic ranges in $\theta^{\ast}$ for every value channel, enforced by projection inside each iteration or as box constraints. This is a linear-algebra methods contribution of the project: it asks how much accuracy and low-rank structure are given up to guarantee plausible values. [Include or omit; projection vs penalty formulation; range table: open.]
- *Time-respecting fitting.* At landmark $t$ an arm may use only bins whose end is $\le t$. LOCF is time-valid by construction (it uses only earlier bins). Normal-value fill is time-valid (age is known at admission). Global low-rank completion across a whole stay is *not* time-valid, because later bins inform earlier fills; arm (b) and arm (c) are therefore fit and folded in on the landmark prefix only, separately for each landmark. A whole-stay completion is allowed only as a labeled look-ahead sensitivity analysis, in the same way as M2 for microbiology.
- *Training-only fitting.* Everything learned from data in an arm (the matrix-completion factors and rank, any data-derived default, and the scalers applied after imputation) is fit on train only and applied unchanged to validation and test (§7). Inside every bootstrap or CV resample it is refit on that resample's train part.
- *Evaluation of the arms.* Every arm is passed through the same downstream analysis: the §8 spectral diagnostics (conditioning and compactness), redundancy (§9), predictive signal at matched width with the frozen ordinal protocol (§10), attribution stability (§11), and the physiologic-plausibility criterion (§12). Attribution to imputed cells and to masks is reported separately for each arm.
- *Masked-known-value RMSE is reported but not primary.* RMSE is computed by hiding a random sample of observed train cells [fraction and seed], imputing them, and comparing with the true values, with subject-bootstrap intervals. This check assumes that the hidden cells resemble the truly missing ones. Under informative missingness that assumption fails (values that clinicians chose not to measure are likely to differ from those they measured), so RMSE is reported alongside the six criteria and is not a primary criterion.
- *Out of scope.* The phenotyping and clustering part of the S36 study (soft phenotyping seeded by clinician labels versus K-means) is not part of this plan.

## 6.7 Sequence models and attribution (Objective 2 with Layer C)

**Sequence models.** Models: GRU, TCN, and a small Transformer encoder [model sizes, grids]. Input per bin: the level's columns, masks, carried-forward flags, time since last measurement, and bin index, and the Layer A static context (the level's Layer A columns) supplied at **every time step** (concatenated to each bin's input, or as the initial state plus per-step conditioning [form: decide]), so that static context conditions each step; padded positions are masked in attention or packing (they never occur inside an eligible prefix), and only bins of the prefix at $L$ are visible. Rows follow the landmark design of §2.3 (V5): for the co-primary analysis the A+B and A+B+C models are fitted separately at each landmark on the encounters eligible at $L$ (one row per encounter, prefix bins $0, \dots, L/6 - 1$); the stacked (encounter, landmark) model with landmark time as a covariate, one network for all 14 landmarks, is a Layer C sensitivity analysis. The head is a cumulative-link (CORAL/CORN-style) ordinal output, trained with the same distance-aware cost on Outcome 1 (and separately on Outcome 2). **Static plus sequential design:** Layer A baseline risk (the ordinal LR on A-$\phi$r, cross-fitted on train) enters only through the fusion head, as an offset, and the sequence network learns a correction to it (v12: the "fused embedding" option is removed; the fusion head receives only the sequence contribution and the estimated baseline risk, and PIM3-like baseline information and the modified PRISM III scalar are kept out of the sequence inputs [whether the baseline-risk model also uses Layer B or the PRISM III scalar: decide]); sequence inputs are read as predictive signals, not causal effects (cumulative-link thresholds $\gamma_j - [s_{\mathrm{static}} + g(x_{\le t})]$, where $\gamma_j$ are the ordered thresholds, $s_{\mathrm{static}}$ is the Layer A baseline score, $g$ is the sequence network, and $x_{\le t}$ denotes the bins up to $t$). Comparators at each landmark: static only (A), **A+B (the baseline of the primary contrast, §10)**, sequence only, and **A+B+C** (static plus sequential, with Layer B entering the static side). The A+B tabular model plus the flattened prefix is no longer an Objective 2 comparator; it survives only inside the labeled flattened baseline of Objective 3 (§12.3, V9). The §10 protocol applies unchanged: light-grid bake-off (tabular winner vs GRU / TCN / Transformer, static plus sequential variants) on validation, the QWK winner (EMD secondary, V6) with the simplicity tie rule [simplicity order: LR < RF < GB < TCN < GRU < Transformer], deeper tuning of the winner only [budget], calibration on validation only, and one logged test evaluation of the per-landmark winners at every landmark (co-primary at the core landmarks), with the stacked sensitivity model scored in the same run.

**Attribution stability for sequences.** TreeSHAP for the tabular winner (A+B); GradientSHAP or DeepSHAP for the sequence models, with permutation importance as a cross-check [method]. Attributions are aggregated at three granularities: (bin, channel), channel (summed over bins), and time block or organ system. For each, Kendall $\tau$ across [$B = 200$] subject-bootstrap refits [refit budget for neural models, possibly fewer refits] and the credit split across temporally adjacent bins, the sequence analogue of the duplicated-column split. Attribution to masks, carried-forward flags, and imputed values is reported separately. Interventional versus conditional SHAP disagreement is reported for the tabular model.

**Matrix diagnostics on Layer C (Objective 1; the tensor analysis is Objective 3, §12.3).** Objective 1 keeps one matrix view of the train landmark prefixes, with the §8 diagnostics: the **per-bin / stacked view** (one $n_k \times q$ matrix per bin $k$, and the stacked $(nb) \times q$ matrix; channel redundancy within a bin and stability of the channel spectrum across bins; rows of one encounter are correlated, so every interval is a subject bootstrap). # 8. Spectral diagnostics and uncertainty

**Object.** $A \in \mathbb{R}^{n_{\mathrm{train}} \times p}$ is the standardized train matrix of a level ($n_{\mathrm{train}} = 9{,}592$ rows, $p$ columns). All quantities come from the singular value decomposition (SVD) $A = U \Sigma V^{\top}$, with singular values $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_{p} \ge 0$ on the diagonal of $\Sigma$, never from $A^{\top}A$, which squares the condition number. Diagnostics need no labels, so all [N_train omitted] train rows are used. $p$ is always reported with $\kappa_2$ and ranks, and levels with different $p$ are compared through principal angles or at matched width $k$, never through raw counts.

| Quantity | Definition used |
|----------------------|-------------------------------------------------------------------------------|
| $\kappa_2$ | $\sigma_1/\sigma_p$, reported as $\infty$ when $\sigma_p$ is below the rank tolerance; $\kappa_2$ over the numerical rank is also reported. |
| Numerical rank | $\#\{i : \sigma_i > \max(n,p)\,\varepsilon\,\sigma_1\}$, where $\varepsilon$ is machine epsilon, with counts at $10^{-3}\sigma_1$ and $10^{-2}\sigma_1$. |
| Belsley condition indices | $\eta_j = \sigma_1/\sigma_j$ with variance-decomposition proportions; a near-dependency is $\eta_j \ge [30]$ with at least two proportions $> [0.5]$. Columns in each null or near-null right singular vector are named. |
| Stable rank | $\lVert A\rVert_F^2 / \lVert A\rVert_2^2$ |
| Effective rank | **Headline: $\sigma^2$ version**, $\exp(H(w))$ with $H(w) = -\sum_i w_i \ln w_i$ and $w_i = \sigma_i^2 / \sum_j \sigma_j^2$. The Roy–Vetterli $\sigma$ version ($w_i = \sigma_i / \sum_j \sigma_j$) is reported alongside, because it is inflated by the noise floor. |
| $k_{95}$ | Smallest $k$ with $\sum_{i \le k} \sigma_i^2 \ge 0.95 \sum_i \sigma_i^2$ (**headline**); the $\sigma$-energy version is reported alongside. |
| Permutation null | Permute each column independently within train rows, recompute $\sigma$, repeat [200] times; count $\sigma_i$ above the 95th percentile of the null. |
| Marchenko–Pastur edge | $\sigma_{\mathrm{edge}} = \sqrt{n}\,(1 + \sqrt{p/n})$ for unit-variance columns. A reference line only: it over-counts on decaying spectra and its i.i.d. assumption fails for one-hot and skewed columns. |
| Decay fits | Power law $\sigma_i = c\, i^{-\alpha}$, exponential $\sigma_i = c\, e^{-\beta i}$, and rank-plus-noise ($r$ free leading values above a flat floor), where $c$, $\alpha$, $\beta$ are fitted constants; fit on the log scale over a fixed index range and compared by BIC. |

**Synthetic planted-rank findings (synthetic_planted_v1, seed 6310, shapes $9505\times 82$ and $9505\times 59$; synthetic only).** $\sigma^2$-energy $k_{95}$, the permutation null, and the MP edge all recover the planted rank 10 (exact rank 10 plus noise 0.01). Decay fits recover $\alpha=1.50$ and $\beta=0.15$ and pick the right family, but on the rank-10 step spectrum they wrongly choose "power", which is why the rank-plus-noise alternative is required. Entropy effective rank and $\sigma$-energy $k_{95}$ are inflated by the noise floor (34 and 70 for true rank 10 at 82 columns), hence the $\sigma^2$ headline. The MP edge over-counts on noise-free decaying spectra (5 against about 2 by permutation). CUR ratios at $k=10$ are always $\ge1$, with CPQR (about 1.5 to 1.6) and DEIM (1.5 to 1.8) better than leverage (2.0 to 3.6) and uniform (2.2 to 3.6). **Not yet tested on planted data and required before real runs:** subject bootstrap of spectra, randomized SVD, Belsley, $U = A(I,J)^{+}$, Davis–Kahan comparison, nonlinear recovery, ordinal classifiers, SHAP stability on a planted redundant group.

**Uncertainty.**

- *Subject bootstrap.* Resample train subjects with replacement [$B = 200$], recompute $\sigma_i$, stable rank, both effective ranks, $k_{95}$, and tolerance counts, and report percentile intervals.
- *Davis–Kahan / Wedin.* For the leading $k$-dimensional right singular subspace, with principal angles $\boldsymbol\alpha$ between the original and the resampled subspace (defined in §9),
$$\lVert \sin\boldsymbol\alpha \rVert_2 \;\le\; \frac{\lVert E \rVert_2}{\Delta_k}, \qquad \Delta_k = \sigma_k - \sigma_{k+1},$$
where $E = A_b - A$ is the bootstrap perturbation (the bootstrap enters as row weights, so $A_b$ and $A$ share rows). Bound quantiles are compared with observed bootstrap angles. The bound is vacuous when $\lVert E \rVert_2 \ge \Delta_k$, and that case is flagged per $k$ [whether Wedin's form is covered in the course notes].
- *Spectral gaps.* Relative gap $g_k = (\sigma_k - \sigma_{k+1})/\sigma_k$ per $k$, with bootstrap intervals. A small gap at $k$ means the rank-$k$ subspace is unstable, and any "rank $k$" statement is qualified accordingly.

# 9. Low-rank approximation, column selection, angles, and recovery

**Eckart–Young and randomized SVD.** Let $A_k$ be the best rank-$k$ approximation of $A$ (the SVD truncated to the $k$ leading singular triples). The identities $\lVert A - A_k\rVert_2 = \sigma_{k+1}$ and $\lVert A - A_k\rVert_F^2 = \sum_{i>k} \sigma_i^2$ are checked numerically for every level and $k$. Randomized SVD (Gaussian sketch, oversampling [10], $s \in \{0, 1, 2\}$ power iterations) is compared with the exact SVD: the error $\lVert A - \tilde{Q}\tilde{Q}^{\top}A\rVert$, where $\tilde{Q}$ is the orthonormal basis of the sketched range, is compared with $\sigma_{k+1}$, and a plain Gaussian sketch serves as a comparison. Fit on train.

**Column selection (CUR).** Notation: $C$ holds $c$ selected columns of $A$, $R$ holds $r$ selected rows, $I$ and $J$ are the selected row and column index sets, and $^{+}$ is the Moore–Penrose pseudoinverse. Rules: uniform, rank-$k$ leverage sampling, top-$k$ leverage, column-pivoted QR (CPQR), DEIM. Middle matrix $U = C^{+} A R^{+}$ and $U = A(I,J)^{+}$. Grid $k \in \{5, 10, 20, 30, 40, 59\}$, $k \le p$. Report $\lVert A - \mathrm{CUR}\rVert / \lVert A - A_k\rVert \ge 1$ in Frobenius and spectral norm; random rules use 50 repeats (median, IQR). **Theory (Drineas–Mahoney–Muthukrishnan 2008):** leverage sampling with $c = O(k \log k/\varepsilon^2)$ columns and $r = O(c \log c/\varepsilon^2)$ rows gives $\lVert A - \mathrm{CUR}\rVert_F \le (1+\varepsilon)\lVert A - A_k\rVert_F$ with constant probability. For each $k$ we report the observed ratio, the smallest $c$ reaching ratio $\le 1+\varepsilon$ for $\varepsilon \in \{0.1, 0.5\}$, and the $c$ the bound requires [explicit constants from the paper].

**Principal angles between level column spaces.** Let $\mathcal{U}, \mathcal{V} \subseteq \mathbb{R}^n$ be two subspaces with $d_U = \dim\mathcal{U} \le d_V = \dim\mathcal{V}$. Their *principal angles* $0 \le \alpha_1 \le \alpha_2 \le \dots \le \alpha_{d_U} \le \pi/2$ are defined one at a time: given the earlier maximizers $u_1,\dots,u_{j-1}$ and $v_1,\dots,v_{j-1}$,
$$\cos\alpha_j \;=\; \max_{u \in \mathcal{U},\; v \in \mathcal{V}}\; u^{\top} v$$
$$\text{subject to} \quad \lVert u \rVert_2 = \lVert v \rVert_2 = 1, \qquad u \perp u_1,\dots,u_{j-1}, \qquad v \perp v_1,\dots,v_{j-1},$$
and $u_j, v_j$ are the maximizers. The angle $\alpha_1$ is the smallest angle between any unit vector of $\mathcal{U}$ and any unit vector of $\mathcal{V}$, and later angles are found in the orthogonal complements of the earlier directions.

*Computation.* For two levels $k$ and $l$ on the same rows, take $\mathcal{U} = \operatorname{col}(X^{(k)})$ and $\mathcal{V} = \operatorname{col}(X^{(l)})$ for the standardized train matrices. Orthonormalize each by a thin QR decomposition, $X^{(k)} = Q_U R_U$ and $X^{(l)} = Q_V R_V$, so that the columns of $Q_U \in \mathbb{R}^{n \times d_U}$ and $Q_V \in \mathbb{R}^{n \times d_V}$ are orthonormal bases of $\mathcal{U}$ and $\mathcal{V}$ (dropping numerically dependent columns so that $d_U, d_V$ are the numerical ranks). Take the SVD of the small matrix
$$Q_U^{\top} Q_V \;=\; P\,\operatorname{diag}(\cos\alpha_1, \dots, \cos\alpha_{d_U})\,S^{\top},$$
whose singular values, sorted in decreasing order, are exactly the cosines of the principal angles; hence $\alpha_j = \arccos\sigma_j(Q_U^{\top} Q_V)$. A singular value equal to 1 is an angle of 0. Cosines near 1 mean shared directions, and $\alpha_j = 0$ for all $j \le d_U$ means $\mathcal{U} \subseteq \mathcal{V}$. Reference nulls: random Gaussian subspaces of the same dimensions in $\mathbb{R}^n$, column-permuted copies, and a split-half null (the same level on random halves of train subjects, comparing leading right singular subspaces in $\mathbb{R}^p$). Intervals by subject bootstrap. Expected: pooling steps (code to chapter to cluster, §1) have zero angles, and the age band, flags, AKI stage, and drug-group features show positive angles.

**Linear versus nonlinear recovery.** For each column added at a level, predict it from the $\phi_0$ columns by ridge regression (linear) and gradient boosting (nonlinear) [kernel ridge optional], 5-fold CV on train grouped by subject. $R^2$ for continuous columns, balanced accuracy for binary flags and stage. Also a kNN mutual-information estimate given the source columns. The gap $\Delta R^2 = R^2_{\mathrm{nonlinear}} - R^2_{\mathrm{linear}}$ is reported by family: z-scores and logs (gap near 0), threshold flags and AKI stage (large gap), pooled categorical sums (linear $R^2 = 1$), drug-group features. *Interpretation:* a threshold flag such as $f_i = \mathbf{1}\{\mathrm{HR}_i > c(\mathrm{age}_i)\}$ (§1) is a deterministic function of its source values, so a tree model recovers it almost exactly (redundant for nonlinear models), while a linear model cannot, so the flag adds a direction in linear algebra. Redundancy is therefore model-class dependent, and both are reported.

**Distance-aware loss and selection.** Let $y \in \{0, \dots, K-1\}$ be the true class, $\hat\pi = (\hat\pi_0, \dots, \hat\pi_{K-1})$ the predicted distribution, and $F_{\hat\pi}(j) = \sum_{i \le j} \hat\pi_i$. The primary ground cost is $C_{ij} = \lvert i - j \rvert$ (maximum $K - 1$). The earth mover's distance (Wasserstein-1 on the ordered classes) is
$$\mathrm{EMD}(\hat\pi, y) \;=\; \sum_{j=0}^{K-2} \bigl\lvert F_{\hat\pi}(j) - \mathbf{1}\{y \le j\}\bigr\rvert \;=\; \sum_{i=0}^{K-1} \hat\pi_i\,\lvert i - y\rvert,$$
so the expected $\lvert i - j \rvert$ cost is the EMD. The ranked probability score is
$$\mathrm{RPS}(\hat\pi, y) \;=\; \sum_{j=0}^{K-2} \bigl(F_{\hat\pi}(j) - \mathbf{1}\{y \le j\}\bigr)^2,$$
the sum of the binary Brier scores of $P(Y \le j)$; it is proper, whereas the EMD is not (it is minimized by a point mass at the median). The plan **trains** with proper, EMD-aligned losses where the model supports them and **selects** models on validation by **QWK** (the primary selection metric, V6, November 16, 2026), computed on the decided class (the median of the predictive distribution, below); the expected $\lvert i - j \rvert$ cost (EMD) is the secondary metric and is reported beside it. *Sensitivity costs (declared):* $(i - j)^2$, whose Bayes decision is the rounded mean, and an optional clinically weighted asymmetric matrix with larger costs for confusions with the death class [include or omit; weights fixed before real data]. The classes are ordered but not equally spaced in clinical terms (the top class is death, and Outcome 1's bands widen from 24 h to over 336 h), which is why the weighted matrix is worth a sensitivity run.

**Note: how the losses relate.** Cost-weighted classification chooses the decision $i$ that minimizes $\sum_j C_{ij}\,\hat\pi_j$; with $C_{ij} = \lvert i - j \rvert$ the expected cost is exactly the EMD to a one-hot truth, and with a general asymmetric $C$ it is a cost-sensitive loss that is no longer a distance. RPS uses the same ordered structure but squares the cumulative differences, which makes it proper and smoother to optimize. A cumulative-link model is a model form (ordered thresholds, shared slopes) trained by a proper likelihood; distance enters only through the decision rule and the metrics. $\lvert i - j \rvert$ gives the median of the predictive distribution as its decision (robust to a thin, far tail); $(i - j)^2$ gives the rounded mean, which a thin far tail pulls. Toy example on Outcome 1 (classes 0–8; true class 2): predicting 3, 4, or 8 costs 1, 2, 6 under $\lvert i - j\rvert$ and 1, 4, 36 under $(i - j)^2$. Second toy: $\hat\pi$ = 0.6 at class 0 and 0.4 at class 8; deciding 0 costs $0.4 \times 8 = 3.2$ under $\lvert i - j\rvert$ (deciding 4 costs $0.6 \times 4 + 0.4 \times 4 = 4.0$), so the median decision is 0; under $(i - j)^2$ deciding 0 costs $0.4 \times 64 = 25.6$ and deciding 3 costs $0.6 \times 9 + 0.4 \times 25 = 15.4$, and the mean $3.2$ rounds to 3. Third toy, EMD versus RPS: true class 3; 0.5 at class 2 and 0.5 at class 4 has EMD 1 and RPS 0.5, the same EMD as a point mass at 4 (RPS 1); EMD cannot tell a hedge around the truth from a confident miss by one, and RPS can. Reports state both.

**Metrics.** *Selection (model choice on validation):* **QWK** of the decided class (V6); EMD (the expected $\lvert i - j\rvert$ cost, averaged over encounters) is the secondary metric. *Primary metric for the Objective 2 comparisons* (the matched-width level comparison and the Layer C gain): **QWK** (A1.7, V6), with EMD secondary. *Reported for every model:* distance-aware loss (EMD), MAE on classes of the median decision, QWK, macro AUROC across cutpoints and per-threshold AUROC and AUPRC for $P(Y > j)$, $j = 0, \dots, K-2$, RPS, ordinal C-index / Somers' D (from $E[Y \mid x] = \sum_{j=0}^{K-2} P(Y > j \mid x)$), calibration per cumulative threshold (slope, intercept, curve), and mortality AUROC; $P(Y > K-2)$, the death threshold, matches the binary mortality target. *Nominal:* accuracy, macro-F1, per-class recall and counts for all $K$ classes, multi-class Brier score, log-loss. All differences come with paired patient-level bootstrap 95% intervals [$B_{\mathrm{eval}} = 1{,}000$]; in the stacked sensitivity model, per-row weighting is used and per-patient weighting is a further sensitivity analysis (per-landmark models have one row per encounter).

**Protocol (five steps, same levels, same splits).**

1. **Bake-off, light grids.** LR, RF, and GB (and MLP if included; and GRU / TCN / Transformer for A+B+C) are fit on train with default or small grids (including class weighting for sparse classes) over the same levels and $k$ grid, and trained with their likelihood- or RPS-aligned losses and scored on validation. The selection score is the validation QWK on Outcome 1 (V6); EMD and the other metrics are reported alongside and are not used to pick the winner.
2. **Winner choice.** Best validation score; a simpler model wins if the paired-bootstrap CI of the score difference includes 0 [simplicity order: LR < RF < GB < TCN < GRU < Transformer].
3. **Deeper tuning of the winner only.** Nested CV on train grouped by subject, or validation-only tuning [choice], with a declared budget [trials and folds].
4. **Calibration on validation only.** Per-cumulative-threshold isotonic or Platt calibration, or ordinal temperature scaling, then monotonicity of the cumulative probabilities enforced. Calibration quality is judged on test only.
5. **Single test evaluation.** The frozen winners (the matched-width level comparison at 24 h; A+B and A+B+C at every landmark, per outcome; the stacked sensitivity model) are scored on test once, with all metrics and bootstrap intervals; the pre-declared sensitivity analyses (Appendix B) that need test scoring are run in the same logged run. The prediction file and its SHA-256 are logged. No model, level, threshold, or metric choice changes after this step.

The same frozen protocol feeds criterion 3 (predictive signal at matched width) for every level. Test-split counts at late landmarks are small (355 eligible and 32 deaths at 336 h; Outcome 2 readmission below 10 at 336 h), so late-landmark intervals will be wide and are reported as such.

# 11. Attribution stability (SHAP)

**Setup.** The attribution models are the ordinal LR and the tabular winner at fixed hyperparameters (from §10), on Outcome 1 ($K = 9$) and, as a secondary analysis, Outcome 2 ($K = 5$). Sequence-model attribution is described in §6.7. Each is refit on [$B = 200$] subject-bootstrap resamples of train. The attribution target is the expected class $E[Y \mid x] = \sum_{j=0}^{K-2} P(Y > j \mid x)$; SHAP is additive over the sum, so the Frank–Hall version is the sum of per-threshold SHAP values. Global importance is mean $\lvert\mathrm{SHAP}\rvert$ per column on a fixed validation sample [sample size].

**Metrics per level.** (i) Kendall $\tau$ between importance rankings over all pairs of refits (median, IQR; a random sample of pairs if cost requires [number of pairs]). (ii) Credit split within pre-registered groups of redundant columns, each member's share of the group's total $\lvert\mathrm{SHAP}\rvert$ and its spread across refits, with group totals reported too, because a group can be stable while member shares are not. Groups come from the derivation graph of $\theta$, for example $\{$HR z-score, tachycardia flag, any organ block containing HR$\}$, $\{$min, median, max, last of a channel$\}$, $\{\mathrm{Cr}_{\max}$, AKI stage$\}$, and the duplicated columns of $\phi_2$-dup. (iii) Interventional versus conditional SHAP (tree path-dependent as the approximation). Interventional SHAP breaks dependence among columns, so the two disagree more as redundancy grows; the disagreement per level is a further redundancy measure.

## 12.3 Objective 3: tensor SVD of Layer C (extension; owner Vinai; stage 16)

**Status and framing.** Objective 3 is an extension beyond the two objectives of the submitted outline (Vinai's decision for v13). Objective 1 (structure, Team 1) and Objective 2 (CUR and prediction, Team 2) are unchanged; Objective 3 does not choose levels, does not change the Objective 2 winner, and does not enter the Objective 2 primary or co-primary analyses. It asks whether the Layer C sequence has a low-dimensional **multilinear** structure, which a matrix analysis cannot see without unfolding, and it is reported as its own section of results with its own hypotheses, metrics, and criteria. It is descriptive and structural; no causal reading.

**Questions.** (Q1) How many patient, temporal, and feature directions does Layer C need (multilinear ranks), and how fast do the mode spectra decay? (Q2) Is a small CP model adequate and stable? (Q3) Do the feature factors group channels of the same organ system, and do the temporal factors form interpretable profiles? (Q4) Is the structure stable across landmarks? (Q5) Does clinical engineering ($\phi_0 \to \phi_1 \to \phi_2$) make the tensor more compact?

**Data objects.** For each landmark $L$ and level $\ell \in \{$raw $\phi_0$, normalized $\phi_1$, engineered $\phi_2$-single (and $\phi_2$-pSOFA as a variant)$\}$, the train landmark tensor
$$\mathcal{X}_L^{(\ell)} \in \mathbb{R}^{n_L \times b_L \times q_\ell}, \qquad b_L = L/6,$$
with $n_L$ the train encounters eligible at $L$ (6,556 / 5,255 / 4,539 / 3,572 / 2,924 / 2,290 / 1,720 at the core landmarks 24 to 336 h, §2.2) and $q_\ell$ the per-bin channels of the level (values, and at the engineered level also masks and flags). Core landmarks are primary; all 14 landmarks are computed for the stability analysis. Validation and test landmark tensors are built the same way.

**Two binding rules.**

1. **Never unfold C.** The tensor is never reshaped into a patient $\times$ (bin, channel) design matrix for any model, selection, or diagnostic of Objective 3. Mode-$n$ unfoldings $X_{(n)}$ appear only as intermediate steps inside the HOSVD and HOOI computations (their left singular vectors are the mode factors) and are never analyzed as data matrices; no CPQR, DEIM, CUR, or spectral diagnostic of §8–§9 is applied to an unfolding in Objective 3. (The flattened analyses of the labeled baseline below are not Objective 3 results: they are computed beside it for comparison, never feed a rank, model, or criterion of Objective 3, and are labeled "flattened baseline" wherever they appear; V9.)
2. **Honor `mask_valid`.** Padding cells (`mask_valid` = 0) never enter a fit, a standardization statistic, an imputation, or an error term. Landmark tensors of eligible encounters contain no padding by construction (§6.1), and acceptance check 4 of §6.8 verifies it. Any analysis on the full 56-bin grid (for example the padding probe below) uses a weighted decomposition with weight 0 on padding; padding is never treated as a zero observation.

**Masks by level.**

| Level | Values entering the decomposition | Missing and imputed cells |
|----------|------------------------------|------------------------------|
| raw ($\phi_0$) | per-bin native-unit summaries, standardized per channel on valid train cells | left as NaN; fit by **masked weighted ALS** with weight 1 on observed cells and 0 on missing cells; masks are reported, not decomposed |
| normalized ($\phi_1$) | the filled copy of §7 (LOCF within cap, then train median) | filled cells enter as values; the imputation flags are kept beside the tensor; sensitivity: weight [0.5] on imputed and carried cells |
| engineered ($\phi_2$) | organ-block channels **plus** masks, carried-forward and imputation flags as additional feature-mode channels | masks are information: missingness structure is part of what is decomposed |

Standardization is per channel over valid train cells pooled across bins [or per bin: decide; the same choice as §6.7]. Triggered tests enter as ordered flag plus released value at the engineered level and as released value with NaN at the raw level.

**Methods.** (i) **Truncated HOSVD:** mode-$n$ singular values $\sigma^{(n)}_i$ for $n = 1, 2, 3$ (patient, bin, feature) and the core tensor. (ii) **Tucker by HOOI** at multilinear ranks $(r_1, r_2, r_3)$ on a grid [$r_1 \in \{5, 10, 20, 40\}$, $r_2 \le b_L$, $r_3 \le q_\ell$], initialized by HOSVD. (iii) **CP by ALS** (Kolda and Bader 2009) for $R = 1, \dots, R_{\max}$ [$R_{\max} = 15$], with [10] random starts plus an HOSVD start; masked weighted ALS at the raw level. (iv) **Model checks:** core consistency (CORCONDIA) per $R$; Tucker congruence of CP factors across starts and across [$B = 50$] subject-bootstrap resamples. (v) **Projection:** validation (and, once, test) tensors are projected onto the train bin and feature factors (fixed), solving only patient loadings by least squares (masked at the raw level); nothing is refit on validation or test. (vi) **Nulls:** a channel-wise patient permutation (each channel's patient order permuted independently, keeping each channel's temporal profile and breaking cross-channel coupling) and the per-bin patient shuffle of §6.7 (breaking temporal dependence).

**Metrics.** Mode-$n$ spectra with $k_{95}$ and $\sigma^2$ effective rank per mode, and the count of mode singular values above each null; the Tucker relative error surface $\lVert \mathcal{X} - \hat{\mathcal{X}} \rVert_F / \lVert \mathcal{X} \rVert_F$ over multilinear ranks (train and projected validation); CP relative error by $R$, CORCONDIA, and congruence; principal angles between temporal (mode-2) subspaces on the shared bins and between feature (mode-3) subspaces across consecutive landmarks; alignment of feature factors with the Table 5.1 organ blocks (share of a factor's top-loading channels in one block, or the adjusted Rand index of a factor-based channel grouping) against a permutation null of block labels; comparison of all of these across levels at matched multilinear rank. **Optional:** patient loadings ($n_L \times R$) as a compact tabular input to the Outcome 1 model at matched width, compared with A+B and A+B+C [include or omit; if included, scored only on validation unless Vinai adds it to the single test run].


**Flattened baseline (labeled; V9, November 16, 2026).** To show what the multilinear view adds, the flattened Layer C analyses are reported beside Objective 3, always labeled "flattened baseline": (i) the §8 spectrum and $\sigma^2$ effective rank of the flattened train prefix matrix $n_L \times (b_L q_\ell)$ against $b_L q_\ell$ as bins are added (former H8; descriptive, against the per-bin patient-shuffle null); (ii) CPQR and DEIM selection of (bin, channel) pairs, compared with the bin and feature factors of the Tucker fit; (iii) if the optional loading-based model is run, the A+B plus flattened-prefix tabular model as its comparator, on validation only. The baseline uses the same tensors, masks, and standardization, is computed in stage 16, and is never used to choose a rank, a level, or a model; it is not an Objective 1 or Objective 2 result. A planted temporal-redundancy case must be visible in it (§13.3).

# 17. Limitations (consolidated)

**Cohort and outcomes.**

- One cohort, one hospital system, one split; intervals reflect subject resampling but not cohort uncertainty. Associations only.
- Landmark cohorts condition on survival and an ongoing ICU stay to $L$, so late-landmark results describe a selected group and class mixes differ by landmark. Test counts at late landmarks are small (355 eligible and 32 deaths at 336 h), and Outcome 2 readmission counts fall below 10 in validation and test at 336 h.
- Outcome 1 level 7 (over 336 h remaining) holds 22% of the eligible at 24 h and 48% at 336 h, so the outcome is top-heavy at late landmarks. Outcome 2 level 0 (post-ICU stay under 7 d) holds 77–87% of survivors.
- Outcome 2 is a surrogate: PIC records no organ function or support at ICU discharge.
- 354 encounters have an ICU span over 1,440 h; span and actual ICU time can differ (100 encounters differ between span and `icu_time_hours`).
- The `keep_both` policy counts a readmission both as an Outcome 2 level of the index encounter and as its own index encounter; the split and bootstrap are by patient, and S12 checks recency features.
- Death attribution follows the inherited rule (the recorded ICU deaths (count omitted from this public copy)); 14 deaths are not on the patient's last encounter (sensitivity 969).
- Encounters with an invalid or missing DOB form the `age_invalid` band (its v1.0.1 counts are suppressed), kept in the primary analysis with two sensitivity analyses.

**Data and features.**

- LOS-based targets interact with windowing and masking; the landmark design removes the open-bin shortcut, and S1–S12 with the S4 probe reduce and quantify the rest.
- Chart-channel masks largely reflect the care unit (the general ICU has almost no charted vitals); first_careunit is kept and a unit-stratified sensitivity analysis is run (D35).
- PIC has no charted FiO2, oxygen device, ventilation status, GCS, or pupils, and blood gases are not marked arterial. P/F, S/F, and the pSOFA respiratory component are dropped (D28, D29); pSOFA is a **five-component modified** score and PRISM III is modified; their published validation does not transfer exactly. The neurologic block relies on drugs, the diagnosis, CSF tests, NSE, and the pain score. The analyser A–a gradient (5210), computed from the same FiO2, is dropped as well (V10).
- Fluid balance and percent fluid overload cannot be built; fluid intake in mL/kg/day is a surrogate (D17). Urine output is charted about once a day, so only the 24 h KDIGO criteria apply (D30).
- Weight is imputed for most encounters (age band $\times$ sex medians; sex-only for `age_invalid`), so weight-normalized channels inherit that error. Weight is used only as a normalizer; neither weight nor its source flag is a feature (V12).
- Bilirubin item 5255 is used only in NICU (D24); 98 non-NICU train encounters lose bilirubin. Neonatal bilirubin largely reflects physiological jaundice, which inflates hepatic pSOFA points in neonates (neonatal sensitivity analysis).
- Laboratory release is assumed at CHARTTIME + 1 h because PIC has no result time (+0 h and +2 h sensitivities).
- Cutoff-implied medication intervals: ENDDATE is missing on 78.07% of prescription rows, so most active flags come from the 12 h / 24 h cutoffs; the state machine measures documented administration plus a fixed cutoff, not true exposure; an ENDDATE at or before $t$ is taken as known at $t$. PRESCRIPTIONS has no infusion rates, so vasoactives are one group with an exposure flag and an agent count, and pSOFA cardiovascular points cannot use doses.
- Microbiology has only a collection time; M3 turnarounds are assumptions stated over a grid; M2 is an upper bound on the leak contribution; the gram class is derived from the organism name; the contaminant and resistance rules are clinical assumptions.
- Preliminary admitting diagnosis only; discharge diagnoses are banned. The inferred admission source is a rule that cannot be checked against a reference standard. The diagnosis-only domain differs from the contract domain (which uses the care unit).
- Surgery: complexity groups do not track duration, so $\phi_1$ uses a type-specific band from frozen medians; 12.5–12.9% of validation and test surgeries have a type unseen in train and use fallback medians; within-type band cells are sparse; 2.2% of keyed intraoperative vital-sign rows fall outside every anesthesia window.
- The † plausibility gates of channel map v2.3 are provisional until the Stage 3 audit reports out-of-gate counts (V13); per-channel dispositions are not yet locked.
- The frozen 3.0 medication rule uses documentation over the whole stay; it is a comparison build only.

**Methods.**

- Layer C: padding is structural and must be masked; LOCF-carried values create temporal duplication; neural models have more tuning freedom and fewer refits for stability.
- Imputation arms: masked-known-value RMSE assumes the hidden cells resemble the truly missing ones, which informative missingness violates; each arm is a single imputation; age-specific normal values and plausibility ranges are clinical assumptions; the motivating study was single-center, adult, and surgical.
- Objective 3: tensor decompositions are non-unique (CP up to scaling and permutation; Tucker up to rotation), so interpretation rests on congruence and stability, not single fits; the raw-level masked fits can converge to local minima; organ alignment depends on the Table 5.1 membership; the padding probe is illustrative.
- QWK is the selection and primary metric (V6), but it is not a proper scoring rule, it weights disagreements quadratically while the decision rule is the median (the $\lvert i - j\rvert$ logic), and it depends on the class mix, which shifts with $L$; EMD and RPS are reported beside it, and QWK is compared only within a landmark.
- The co-primary Layer C models are fitted per landmark (V5), so late landmarks have few rows (train 1,720 at 336 h); the stacked sensitivity analysis shows what pooling across landmarks changes.
- The flattened Layer C analyses are a labeled baseline of Objective 3 only (V9); Objective 1 no longer tests temporal redundancy in the flattened view (former H8).
- The schedule is compressed (builds Nov 15–20 overlapping test scoring); stages may be reduced in scope (§16).
- Synthetic validation shows the methods recover planted structure; it says nothing about PIC values. The synthetic dataset predates D29 and is kept as is (V11); its tests run without the dropped channels, so they do not exercise the exact real schema.
